# Gauntlet Pass 2

Date: 2026-08-11. Review mode: the same three read-only subagents re-inspected changed files and ran focused tests with fresh context. No P0 was active while all V2 flags remained off. The pass was not clear.

## Verified repairs

- The 1,500-character-only false denial is gone and the current boundary is 800.
- Schema v5 no longer makes an optional Recognition lab mandatory.
- Direct quality/parse rejection releases course capacity; failed product events release the request allowance.
- Retry payloads are fingerprint-bound.
- Nested relationship and capability IDs affect publication fingerprints.
- Author readiness shows stable codes, paths, actions, warnings, and snapshot metadata.
- Classification, scenario, and signal selected state now uses `aria-pressed`.

## P1 blockers found in pass 2

1. Runtime repair still regenerates and overwrites a whole lesson. The V2 repair planner/state machine are not runtime authorities.
2. Manual review is terminal: no human-resolution mutation or approval-to-publication path exists.
3. Stable objective IDs and assessment mappings do not exist.
4. Lab/visual applicability is registry-only and not connected to planning, generation, validation, or learner progress.
5. Claim-level evidence retrieval/support validation is absent.
6. Legacy migration/compatibility adapters and immutable published releases are absent.
7. The 100-row request corpus has no generation runner, recorded artifact fixtures, or outcome scorer.
8. Shadow mode has no durable V1/V2 comparison store or diagnostic timeline.
9. Accessibility automation, visual regression, and valid authoring screenshots are absent.

## Findings fixed after the pass

- Unsupported `code-tracing` was removed from the registry.
- AI usage finalization now no-ops unless the request remains reserved.
- V2 reports now list only rules actually executed and name skipped lanes.
- Candidate hashing canonicalizes course and lesson documents separately, excluding publication workflow metadata while retaining nested IDs.
- V1 and V2 prompt versions are explicitly separable; V2 provenance is written only under the pipeline flag and no longer claims an evaluator or repair version that did not run.
- Requested-language instructions no longer hard-code English; current-regulation and several high-risk phrases route conservatively while mathematical "Law of Large Numbers" does not.
- Unsupported visuals receive their own code rather than masquerading as a missing essential visual.

## Verdict

Not release-ready. Pass 2 found new release blockers, so the required two consecutive clear passes have not occurred.

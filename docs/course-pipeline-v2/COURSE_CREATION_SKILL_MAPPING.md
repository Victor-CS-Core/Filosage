# Course-Creation Skill Mapping

The only repository teaching skill is `.agents/skills/teach/SKILL.md`. It is a stateful HTML teaching-workspace workflow, not a production course generator, and runtime code never imports it.

| Teach strategy | Filosage runtime translation | V2 status |
|---|---|---|
| Concrete mission and observable success | Course brief goal, outcome, artifact, capstone | Present with stable objective and assessment IDs in V2 |
| Zone of proximal development | Background, level, prerequisites, sequence | Present as prompt/schema fields |
| Trusted resources; distrust parametric knowledge | Source pack with untrusted-data isolation | Metadata only; retrieval/claim evidence missing |
| Short, tightly scoped lessons | Lesson plan and time bounds | False 1,500-character denial fixed |
| Retrieval, spacing, interleaving | Quizzes, reviews, learner progress | V2 objective-to-lesson-to-assessment coverage is deterministic; longitudinal spacing remains a learner-runtime concern |
| Immediate feedback | Quiz option feedback, Recognition v2 | Present for some capabilities; not all labs persist |
| Reusable components | Typed interaction and visual renderers | Present and now versioned in registries |
| Beautiful, accessible references | Structured HTML/React learner runtime | V2 persists applicability, objective mapping, provenance fields, and fallback policy; complete accessibility evidence remains pending |
| Community wisdom | External community recommendations | Not adopted as a publication requirement |
| Equal-length quiz answers | Formatting heuristic | Intentionally not a hard gate |

Production correctness is defined by TypeScript schemas, registries, rules, tests, and evals. The Markdown skill remains design input only.

# Capability preservation and bounded repair

The course's saved single-win objective is the capability contract for new lesson generation. Source evidence constrains factual support; it does not authorize changing that capability into a source-copying drill. New lesson generation keeps the saved objective label, teaching mode and linked assessment/criterion plan. A changed objective triggers `LEARNING_DESIGN_REPLAN_REQUIRED` after bounded generation correction; no replacement lesson is saved. Matching an objective label is a structural safeguard, not semantic evidence that the activity actually teaches it.

Source-backed instruction can use several independently supported factual sentences within the existing eight-citation schema. Each sentence still needs one assigned atomic claim, its exact source/evidence identifiers, one unique verbatim sentence occurrence and the correct lesson section. The independent whole-lesson verifier must assess every citation and reject unsupported or uncited facts. One supported sentence cannot authorize a second assertion. Hypothetical exercise inputs do not authorize unsupported domain rules, calculations, recommendations or causal conclusions. The prompt asks for all materials needed to solve the promised practice and retains the saved explanation budget without adding a minimum word target.

An invalid course learning plan throws a typed blocker with the real existing `LearningDesignContract` findings. R08 integrates this helper before its final course/accounting commit: the operation saves a recoverable failure and refunds once, so the same blocked request does not trigger an automatic paid rerun. Reviewers must verify that integrated path on the final release candidate; the helper alone does not prove persistence or refund behavior.

Recovery uses available product paths. The author returns to Course Studio, revises the goal, constraints or source material, and deliberately submits a new course request. This creates a newly linked plan; it does not silently rewrite an existing course's objective, practice, quiz, criteria or capstone. Existing author content remains intact. A comprehensive in-place semantic course-replanning editor is not implemented by this change. R09 owns durable lesson-operation replay and recovery integration.

Automatic repair remains limited to the existing allowlisted structural actions: removing invalid optional lab/visual blocks and adding an accessible fallback derived from already validated lesson text. The semantic repair attempt allowance is zero. Retained typed operation vocabulary does not imply an executable semantic subtree repair path, and no deterministic repair creates semantic review proof. Other findings require explicit author regeneration/review or a new course plan.

Sequence-interaction curation now preserves authored guidance, including requested non-English teaching. Only the existing explicit English `first ... then ... finally` ordering giveaway receives the neutral English prompt. English interface buttons and accessible movement controls remain English. This is not a comprehensive multilingual answer-leak detector or accessibility certification; generated-language and browser review remain required.

Local fixtures verify objective drift, actual contract blockers, multiple atomic citation bindings, unsupported second claims, concise valid lessons, optional labs and preservation of Spanish prompts. Actual lesson solvability, transfer quality, culturally competent teaching, supported-domain breadth and full-course semantic quality require R13 evaluation and competent catalog review. No paid provider call or browser acceptance is implied by these fixtures.

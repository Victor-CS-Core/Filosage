# AppCreator reference for future native apps

Victor asked on September 6, 2026 to retain AppCreator for later use.

**Tool:** AppCreator by Paul Solt / Super Easy Apps.

- Author's page: https://super-easy-apps.kit.com/app-creator
- Public toolkit copy: https://github.com/robertguss/claude-code-toolkit/blob/main/skills/mobile-app-dev/ios-mac-app-creator/app-creator/SKILL.md

It targets native iOS/macOS development: XcodeGen scaffolding, Makefile build/test commands, readable build diagnostics and optional task tooling. Existing-project adoption can add selected tooling without regenerating the app. The public copy reviewed in this conversation identifies version 0.9.8; verify the author's current distribution, full scripts and license before future installation.

**Project decision:** keep it as a candidate for a future FiloSage iPhone or Mac client. The current FiloSage application remains Next.js/React on Azure. This note does not install the skill, authorize a native-client project, grant tool access or apply its instructions to the web app. Reassess it when native development is explicitly selected.
